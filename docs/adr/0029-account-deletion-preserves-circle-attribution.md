# Account deletion preserves Circle attribution

Account Deletion removes the User's login identity, app profile, User-owned Notifications, User-scoped email-event records, Personal Circle, and archived regular Circles the User owns with no active co-Members, but it does not rewrite immutable Circle, Transaction, or Category History. Non-owner memberships become Deleted Members: they lose access, keep Display Name for financial attribution, drop Profile Picture, never count toward Circle Capacity, and are never reconnected to a future User even if the same person signs up again. We chose this over strict history anonymization because shared finance auditability depends on knowing which historical Member did what, while deleting live User-owned profile data and access still honors the product meaning of deleting an account.

Account Deletion is blocked while the User owns a setup-complete active regular Circle with no active co-Members or any regular Circle with active co-Members. A solo setup-incomplete regular Circle is disposable and deleted automatically. A regular Circle with active co-Members must be transferred first; ownership transfer is allowed while archived as a narrow lifecycle exception to read-only behavior. Deletion finalization re-checks blockers after email verification. Pending Invitations created by or addressed to the deleting User are revoked and recorded in Circle History, but Account Deletion does not create Notifications for other Users.

The User confirms with the exact phrase `DELETE MY ACCOUNT`. The email verification link requires a current authenticated session for the same User; an absent or expired session requires signing in and reopening the link. Successful verification immediately and irreversibly removes login access and signs the User out. Physical deletion of eligible owned Circle data is durable, idempotent, and bounded; it may continue after sign-out, but no access, grace period, or undo remains. We reject a single unbounded cascade transaction because Circle financial data and History grow without bound.
