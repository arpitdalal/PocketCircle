# Home Summary reports User-attributed cash flow by Currency

The authenticated `/` route is PocketCircle's **Home Summary**: a User-level cash-flow report plus Circle navigation, distinct from every per-**Circle** **Dashboard**. It aggregates active **Transactions** whose **Paid By** resolves to the current User across the visible Circles included in Home Summary reporting. **Recorded By** does not control reporting attribution. The page labels the report **Cash flow** and shows Income, Expenses, Net cash flow, a monthly trend, per-Circle contribution, and recent attributed Transactions; the existing active and Archived Circle cards remain as navigation below it.

Home Summary reports one **Currency** at a time. A currency selector switches among currencies represented by visible Circles, including currencies whose Circles are all currently excluded, defaulting to the Personal Circle's Currency; the selected Currency is URL-owned. PocketCircle never converts or adds differently denominated amounts. Each currency therefore has a separate, internally valid report rather than one misleading nominal total.

The time control defaults to the current month and offers 1, 3, 6, or 12 calendar months ending with the current month; a custom date range is deferred. Income, Expenses, and Net cash flow aggregate the entire selected range, while the trend presents the same range month by month. Every metric, recent row, and per-Circle contribution uses the same Currency, range, Circle inclusion, active-Transaction, and Paid-By-User scope.

Every visible Circle is initially included and newly visible Circles join the report automatically. A User can persistently exclude or re-include a Circle. Inclusion survives Circle archival so historical numbers do not silently change; loss of Circle access removes its data under normal Circle Visibility. This preference affects Home Summary reporting only: it never hides Circle cards, changes the Circle switcher, changes access, or changes a per-Circle Dashboard. The UI always exposes its scope, including Currency and included-versus-available Circle count.

**Paid By** measures whose money moved, not who economically consumed a shared Expense. A trip advance therefore appears as the User's full cash outflow until repayment is recorded as Income; excluding the trip can create an everyday-cash-flow view but cannot calculate the User's trip share. Home Summary does not claim account balance, net worth, a User's allocated share, or receivable/payable position because PocketCircle has no accounts, opening balances, splits, Settlement, or Member balances. Reimbursement linkage and share allocation require separate domain decisions.

The first release deliberately has no cross-Circle Category analytics or global Transaction list/Search. Categories are Circle-scoped, names can collide, and multi-Category totals are non-additive. Headline totals and the trend are read-only; per-Circle contribution links to that Circle's Dashboard, recent rows link to Transaction detail, and Circle cards retain canonical navigation. Cross-Circle search, custom date ranges, foreign-exchange conversion, and changes to existing per-Circle Dashboard range semantics remain separate work.
