# PostHog for product analytics

PocketCircle uses PostHog for product analytics from the start of beta, without PostHog Session Replay in v1. New Users default to analytics enabled after onboarding disclosure; existing stored preferences are not backfilled. The Settings → Privacy switch is the persisted opt-out and later opt-in control. PostHog initializes only after onboarding completes and only while that preference is enabled. The SDK uses in-memory persistence, starts capture opted out, then enables capture when the backend preference allows it. Person profiles are never created. Withdrawal stops capture, resets in-memory PostHog state, and makes subsequent track() calls no-ops. Analytics events must avoid financial content such as Transaction titles, notes, exact amounts, and free-form Feedback text, focusing instead on product flow events, feature usage, and aggregate-safe metadata.
