# PostHog for product analytics

PocketCircle uses PostHog for product analytics from the start of beta, without PostHog Session Replay in v1. New Users default to analytics enabled after onboarding disclosure; existing stored preferences are not backfilled. The Settings → Privacy switch is the persisted opt-out and later opt-in control. PostHog initializes only after onboarding completes and only while that preference is enabled. The SDK uses in-memory persistence. Capture is gated by the backend preference and a before_send filter; PostHog's persisted consent APIs are unused because they only write localStorage or cookies. Automatic URL, path, referrer, and title properties are stripped from outgoing events. Person profiles are never created. Withdrawal stops capture, resets in-memory PostHog state, and makes subsequent track() calls no-ops. Analytics events must avoid financial content such as Transaction titles, notes, exact amounts, and free-form Feedback text, focusing instead on product flow events, feature usage, and aggregate-safe metadata.
