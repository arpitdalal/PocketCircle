# PostHog for product analytics

Spend Circle uses PostHog for product analytics from the start of beta, without PostHog Session Replay in v1. Product analytics are disabled by default for every User. A User can explicitly opt in or withdraw consent in Settings -> Privacy; the preference is persisted on the User profile, and PostHog is not initialized until consent exists. Withdrawal stops capture and clears PostHog's local analytics state. This global opt-in rule avoids relying on inferred location while satisfying jurisdictions that require prior consent. Analytics events must avoid financial content such as Transaction titles, notes, exact amounts, and free-form Feedback text, focusing instead on product flow events, feature usage, and aggregate-safe metadata.
