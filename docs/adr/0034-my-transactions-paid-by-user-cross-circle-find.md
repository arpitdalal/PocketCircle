# My Transactions is the Paid-By-User cross-Circle find surface

ADR 0031 deferred cross-Circle Transaction list/Search. That work is **My Transactions**: one additive primary destination (`/my-transactions`) that combines list + text search + structured filters for **Transactions** whose **Paid By** resolves to the current **User**, regardless of **Recorded By**. It is not a Global Monthly Ledger, not Member-visible Circle browse, and not a second Home Summary.

Scope stays find-oriented: default all-time; URL-owned filters (text, Circle, type, lifecycle defaulting to all, date range, amount range); numbered pagination; sort by Transaction Date descending then created-at descending; rows show Circle and Currency; Edit when the Circle is active and the User may edit; no cash-flow totals and no Export in v1. Circle filter defaults to all visible Circles (including Archived Circles the User can still view) and is independent of Home Summary inclusions. Category and Recorded By filters are deferred because Categories are Circle-scoped. Per-Circle **Monthly Ledger** and **Transaction Search** remain. Home links through from recent Transactions; launch also uses Feature Announcement and What's New.
